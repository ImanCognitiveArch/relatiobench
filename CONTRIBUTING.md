# Contributing

Start with a concrete workflow or failure case. Include scenario version, package version, reproduction command, observed trace and expected behavior. Use synthetic/anonymized minimal examples; never submit credentials, raw clinical records or participant-identifying content.

Run the contract tests and add a meaningful regression case for a changed behavior. Changes to event meanings, schemas or metric definitions require a versioned contract decision and compatibility note. Preserve failing results; do not edit thresholds to rescue a policy.
