# Pre-launch review — 2026-11-23

## Corrections to the suggested positioning
- No measured basis exists for "90% complete", an error-free history, a two-button launch or guaranteed virality.
- The current minimum is Python 3.11, package version 0.1.0a1. Python 3.10 and stable version 0.1.0 are not claimed.
- The implemented product is a local synthetic scenario/replay and scoring bench.
  It has no ROS 2 nodes, Gazebo bridge, psychometric signals, patient model or empathetic interaction model.
- Core engineering checks, CI jobs, independent human use and clinical validity are different evidence.
- Apache-2.0 grants rights subject to its conditions, including a limited express
  patent license for relevant contributor claims. It is not universal patent
  clearance or a requirement for every B2B buyer.
- Redistribution obligations depend on the license's terms: relevant notices
  must be retained, and NOTICE attribution can be reproduced in specified
  permitted locations. This does not require every user to display the author's
  name prominently, preserve an identical file in every circumstance, endorse
  the author or provide an academic citation.
- CITATION.cff supplies software citation metadata. It does not confer peer review,
  publication acceptance, scientific validation or a DOI.
- No sourced evidence supports a universal threefold platform ranking benefit
  from a video/GIF. Use media to demonstrate actual behavior.
