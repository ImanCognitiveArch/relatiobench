## LinkedIn — release-ready copy (only after the gates above)

A policy can make zero mistakes by doing nothing.
That is why "no violations" is not enough.

I built RelatioBench to make that distinction visible.

The engineering alpha replays authored interaction scenarios and scores recorded actions independently of the policy. Two small contexts—a social-robot activity and virtual role-play—compare three baselines:

• Respect the controls and complete permitted tasks.
• Deliberately ignore pause, withdrawal and level bounds.
• Always stop: zero violations, zero completed tasks.

You get JSON traces, explicit metric denominators and a local HTML comparison.

Python 3.11+. No model key, ROS installation or GPU.
Apache-2.0. Twelve contract tests and six Linux/Windows CI jobs passed for the reviewed alpha.

This release tests behavior on synthetic fixtures. Human/clinical validity and ROS/Gazebo integration remain future work.

Try it:
python -m pip install relatiobench==0.1.0a1
relatiobench demo --output ./demo-output

https://github.com/ImanCognitiveArch/relatiobench

## Distribution experiment
Success for the first cycle: one external builder reproduces a run and provides
one actionable friction report. Track views, substantive replies, verified runs,
repeat use and paid interest separately. No promise of monthly trends, an
algorithmic multiplier or revenue. Prefer a relevant reproducible example over
unverified claims about what all robots or clinicians can or cannot do.

After 48-72 hours, review observed responses and refine the explanation. Do not
send unsolicited repeat messages or treat likes/stars as independent validation.
